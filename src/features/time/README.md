# Time by project

One answer a week: the projects she is assigned to that week, and how many days on each — in
halves, seven at most, a second answer replaces the first. `monthElements` gives, per person, the
days by project, approved leave by kind and the weeks without an answer: what the accountant needs.
No pay is computed. `time_by_project` is the same as a data set, under `team:read`.
